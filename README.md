# 🔒 Sistema Inteligente de Controle de Acessos

Script em Python que simula um portal de controle de acessos interativo via terminal, com verificação de base de dados, validação de maioridade e fluxo para novos cadastros em tempo de execução.

## ⚙️ Funcionalidades

* **Consulta em Banco de Dados Simulado:** Valida se o usuário já possui registro na lista de cadastros oficiais.
* **Validação de Maioridade:** Libera ou bloqueia a catraca com base na idade informada (`idade >= 18`).
* **Cadastro Dinâmico:** Permite a inclusão de novos usuários na base de dados em tempo real caso o nome não seja encontrado.

## 🛠️ Tecnologias Utilizadas

* **Python 3** (Listas, Estruturas Condicionais `if/else`, Manipulação de Strings e Entrada de Dados via Terminal).

## 🚀 Como Executar o Projeto

1. Certifique-se de ter o Python 3 instalado no seu sistema.
2. Clone este repositório ou baixe o arquivo `main.py`.
3. Abra o terminal na pasta do arquivo e execute:
   ```bash
   python main.py
